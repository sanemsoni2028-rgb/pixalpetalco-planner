# PixalPetalCo Planner: online copies

This repository only hosts the online copies that the QR codes in the PixalPetalCo products open:

- `/2027/app/` — **2027 Interactive Planner** (opens from the QR code in START HERE; works offline once opened)
- `/2027/budget/` — **2027 Interactive Budget Planner** (opens from the QR code in its START HERE; works offline once opened)
- `/2027/` — setup help for the 2027 PDF planners (GoodNotes, Notability, Noteshelf, Xodo)
- `/` — Life OS Planner (older product)
